## Third-party components

Dependencies are installed separately. See [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md) for license information and source links. In particular, PyMuPDF/MuPDF has AGPL/commercial licensing; it is not MIT. Hancom Office has separate vendor terms.

No virtual environments, package wheels, Hancom binaries, or security DLLs are bundled. Anyone redistributing dependencies or providing a combined service must review the exact versions and applicable license obligations.

## Public repository contents

The repository contains runtime source, skill instructions, reference documentation, templates, synthetic examples, tests, and CI configuration. Test-signature images are marked as synthetic and are not a real person's signature.

Private documents, real signatures, customer information, credentials, runtime logs, internal project plans, completion ledgers, and application drafts are not included.
