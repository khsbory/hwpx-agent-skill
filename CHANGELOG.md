# Changelog / 변경 기록

## Initial public source

- HWPX document generation, inspection, targeted editing, fixed-form filling, and merged/nested table extraction.
- Windows/Hancom signature-image insertion, HWP-to-HWPX conversion, and PDF export with an explicit cooperative `--exclusive-use` mode.
- Checked ZIP/XML processing, path-alias protections, staged output validation, and original-file preservation.
- Owned Python helper containment on Windows and conservative Hancom session cleanup without native force-termination.
- Synthetic fixtures, non-COM regression tests, and CI configuration; actual Windows/Hancom synthetic acceptance is documented separately from mocked tests.
- English and Korean README documents, installation instructions, support limits, security guidance, and third-party license notices.
